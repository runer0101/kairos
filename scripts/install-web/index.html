Qué hará el instalador

  • Clona o actualiza el repositorio en ~/.config/kairos.
  • Instala lo que falte: Node.js, pnpm, OpenCode y engram.
  • Instala las dependencias con el lockfile congelado.
  • Enlaza el lanzador kairos (y kai, ks) y los temas.
  • Sincroniza con gentle-shell si está instalado.
  • Verifica que OpenCode carga los perfiles antes de terminar.

Es idempotente: puedes ejecutarlo de nuevo para reparar la instalación. No instala Ollama ni descarga modelos.
